Privacy Policy

DevOps Genius Zone Bot · Last updated: 13 November 2026

What this app is

DevOps Genius Zone Bot is a private automation tool used only by the owner of the DevOps Genius Zone YouTube channel to upload and manage videos on that channel. It is not offered to other users.

Google user data the app accesses

With the channel owner's consent, the app uses these YouTube Data API permissions for the owner's own channel only:

  • youtube.upload: upload videos and set thumbnails.
  • youtube: read the channel's basic details (to confirm the correct channel) and add videos to playlists.
  • youtube.force-ssl: upload caption (subtitle) files.

How data is used and stored

  • The OAuth token is stored only as an encrypted GitHub Actions secret in the owner's repository and is used only to perform the actions above.
  • No Google user data is sold, shared with third parties, or used for advertising.
  • The app does not collect data from viewers or from any other Google account.

Google API Services User Data Policy

The app's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions.
